# copier-fastapi-svelte

Agent-ready Copier starter: FastAPI, Svelte 5, TypeScript, Vite, Tailwind, shadcn-svelte, SQLite WAL, Caddy and FastMCP.

```sh
uvx --from copier copier copy gh:RuchirChawdhry/copier-fastapi-svelte my-app
cd my-app
task setup
task dev
```

Optional Taskiq/Redis and ttyd/xterm.js are off by default. Five themes, Ctrl+K, context menus and browser notifications are standard. See the generated README and AGENTS.md.
