# Frontend performance

Run the Frontend benchmark workflow manually to compare the original SvelteKit/Superforms template, the standalone Svelte/TanStack Form migration and the current TanStack Query implementation. All options are disabled. Each revision is rendered and built independently on the same runner with the same browser viewport; nine new browser contexts measure first contentful paint and a real seeded note becoming visible. The report includes total built JS/CSS sizes (raw, gzip, Brotli), initial requested JS, and build duration. JSON samples and resolved lockfiles are uploaded as artifacts. This is a matched-run smoke benchmark, not a controlled microbenchmark or a WAN/Caddy deployment test; the first migration also includes accessibility UI changes. No unsupported performance claim is made from source inspection alone.
