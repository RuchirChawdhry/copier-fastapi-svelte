# Screenshots

Run the manually triggered **Screenshots** workflow to capture the generated app at 1280 × 800 using Playwright. PNGs are committed here after a successful run. The workflow also uploads an artifact.


Includes the command palette and context menu with icons, settings switches, TanStack validation, the optional SJSF form, diagnostics, toasts and all five themes.

- `10-dropdown-menu.png` — workspace actions dropdown.
- `11-sidebar-collapsed.png` — icon-only sidebar; expanded sidebar appears in the existing overview and other screen captures.

- `12-navigation-menu.png` — developer resources navigation.
- `13-date-range-popover.png` — creation-date filter and range calendar; pagination and scroll area appear in the existing overview.
